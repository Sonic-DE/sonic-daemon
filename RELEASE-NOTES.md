# Sonic Daemon Release Notes

Sonic Daemon is the background service that runs many of SonicDE's small helpers, such as device notifications and settings watchers.

## 6.31.0 (2026-10-20)

- The background service no longer looks for a Wayland window manager when it starts, since SonicDE doesn't use Wayland.
- Behind the scenes: version update.

## 6.30.0 (2026-09-12)

- Behind the scenes: version update.

## 6.29.0 (2026-08-07)

- Behind the scenes: restored the code formatting settings and added support for developers' code-navigation tools.
